# W1-CCG 完整流程、最坏需求点诊断与最坏分布边界

日期：2026-09-29  
状态：当前代码口径的权威说明；后续讨论优先读取本文。  
适用实现：`WassersteinBoxInput`、`WassersteinBoxOracle`、`ContextualWassersteinBoxCcgSolver`。  

## 0. 最重要的结论

当前实现能够精确求解 bounded-box、scaled-\(L_1\) 1-Wasserstein 两阶段采购模型，并在收敛时认证：

1. 最优承运人组合 \(y^\star\)；
2. Wasserstein 最坏期望成本；
3. 对偶运输预算价格 \(\eta^\star\)；
4. 每个中心样本对应的一个代表性最坏需求点；
5. 需求主要被推向哪些 lane 的 lower/upper 端点。

但是，当前实现**没有显式恢复完整的最坏概率分布**。原因是 oracle 只回答“从中心样本出发，哪个需求位置最有威胁”，没有回答“应当向该位置搬运多少概率质量”。因此：

\[
\boxed{\text{最坏目标值和决策是精确的，但当前输出的 worst-demand 字段是 oracle 诊断，不是完整最坏分布。}}
\]

如果需要得到完整最坏分布中每个原子的概率，需要在 CCG 结束后增加一个运输 LP，见第 10 节。

## 1. 输入与中心经验分布

给定当前 query，contextual 方法为历史需求样本产生权重。删除严格零权重样本并重新归一化后，保留

\[
\hat d^1,\ldots,\hat d^S,
\qquad
\pi_s>0,
\qquad
\sum_{s=1}^S\pi_s=1.
\]

中心经验分布为

\[
\widehat P=\sum_{s=1}^S\pi_s\delta_{\hat d^s}.
\]

Wasserstein 求解器本身不读取协变量，只接收“需求样本位置 + 样本概率”。因此：

- 等权重输入对应基于 SAA 的 Wasserstein；
- kernel/RF 权重输入对应 contextual Wasserstein；
- 更换 contextual 权重方法不需要改 W1 求解器。

当前正式 contextual W1 中，逐 lane box 的 lower/upper 由**正权重训练样本**的逐 lane 最小值和最大值确定。零权重样本既不属于中心分布，也不再扩大该 query 的支撑区间。当前不再使用旧记录中的 1.5 倍训练最大值。

## 2. 当前二阶段采购值函数

固定承运人选择 \(y\) 和需求 \(d\)，二阶段成本为

\[
\begin{aligned}
Q(y,d)=\min_{x,v,u\ge0}\quad
&\sum_{i,j}r_{ij}x_{ij}+\sum_je_jv_j+\sum_ih_iu_i\\
\text{s.t.}\quad
&\sum_i x_{ij}+v_j=d_j, &&\forall j,\\
&\sum_jx_{ij}+u_i\ge p_i y_i, &&\forall i,\\
&\sum_jx_{ij}\le M_i y_i, &&\forall i,\\
&x_{ij}\le q_{ij}y_i, &&\forall i,j\text{ eligible}.
\end{aligned}
\]

其中：

- \(x_{ij}\)：合同运输量；
- \(v_j\)：现货运输量；
- \(u_i\)：承运人 \(i\) 的 MQC 不足量；
- \(Q(y,d)\)：给定承运人组合后，需求 \(d\) 下的最优运输、现货和 MQC 成本。

因为现货变量可以补足任意 box 内需求，二阶段始终可行。\(Q(y,d)\) 是关于 \(d\) 的凸分段线性函数。

## 3. Wasserstein 歧义集到底允许什么变化

当前 scaled-\(L_1\) 地面距离为

\[
c(d,\hat d^s)
=\sum_{j=1}^J\frac{|d_j-\hat d_j^s|}{\tau_j},
\]

其中 \(\tau_j>0\) 是 lane 尺度。支撑集合为

\[
\mathcal D=\{d:\underline d_j\le d_j\le\overline d_j,\ \forall j\}.
\]

当前正式实现取

\[
\tau_j=J\,\overline d_j,
\]

所以

\[
c(d,d')=\frac1J\sum_j\frac{|d_j-d'_j|}{\overline d_j},
\]

即逐 lane 用当前正权重支撑上界做 max 标准化，再对 \(J\) 条 lane 取平均。因而当前半径是无量纲的“平均标准化需求移动距离”。

W1 歧义集为

\[
\mathcal P_\varepsilon
=\left\{P:\operatorname{supp}(P)\subseteq\mathcal D,
\ W_1(P,\widehat P)\le\varepsilon\right\}.
\]

Wasserstein 半径限制的不是某个样本概率的单独变化量，而是从中心分布向新分布搬运概率质量时的平均运输成本：

\[
\sum_s\int c(d,\hat d^s)\,\Gamma_s(\mathrm d d)\le\varepsilon,
\]

其中 \(\Gamma_s\) 表示从中心原子 \(\hat d^s\) 向其他需求位置搬出的质量。

原始 DRO 问题为

\[
\min_{y\in\mathcal Y}
\sup_{P\in\mathcal P_\varepsilon}
\mathbb E_P[Q(y,D)].
\]

## 4. Wasserstein 对偶：为什么出现 \(\eta\) 和 sample-wise oracle

固定 \(y\) 后，Kantorovich 对偶将内层最坏分布问题转化为

\[
\sup_{P\in\mathcal P_\varepsilon}\mathbb E_P[Q(y,D)]
=\min_{\eta\ge0}
\left\{
\eta\varepsilon+
\sum_{s=1}^S\pi_s
\sup_{d\in\mathcal D}
\left[Q(y,d)-\eta c(d,\hat d^s)\right]
\right\}.
\]

\(\eta\) 是 Wasserstein 运输预算的对偶价格。对每个中心样本 \(s\)，内部最大化

\[
\Phi_s(y,\eta)
=\sup_{d\in\mathcal D}
\left[Q(y,d)-\eta c(d,\hat d^s)\right]
\]

在“移动后采购成本”和“离开历史样本的距离代价”之间权衡。因此最坏需求点不是机械地等于最大需求，而是使

\[
Q(y,d)-\eta c(d,\hat d^s)
\]

最大的需求位置。

引入 \(t_s\) 后，完整对偶模型为

\[
\begin{aligned}
\min_{y,\eta,t}\quad
&\eta\varepsilon+\sum_s\pi_st_s\\
\text{s.t.}\quad
&t_s\ge Q(y,d)-\eta c(d,\hat d^s),
&&\forall d\in\mathcal D,\ \forall s.
\end{aligned}
\]

困难在于每个 \(s\) 都对应无限多个 \(d\)，因此需要 CCG。

## 5. CCG 的完整流程

### 5.1 初始化

对每个中心样本只放入名义点：

\[
\mathcal K_s^{(0)}=\{\hat d^s\}.
\]

初始 master 只知道历史需求，没有预先枚举 box 内其他需求点。

### 5.2 Restricted master

在第 \(r\) 轮，master 只对已经生成的需求点 \(d^{sk}\in\mathcal K_s^{(r)}\) 建立约束：

\[
\begin{aligned}
\min_{y,\eta,t}\quad
&\eta\varepsilon+\sum_s\pi_st_s\\
\text{s.t.}\quad
&t_s\ge Q(y,d^{sk})-\eta c(d^{sk},\hat d^s),
&&\forall s,k.
\end{aligned}
\]

每个生成点都有一套二阶段合同运输、现货和 MQC 变量，所以加入新点时同时增加变量块和约束块，这就是 column-and-constraint generation。

master 得到

\[
y^{(r)},\qquad\eta^{(r)},\qquad t_s^{(r)}.
\]

因为 master 只看过有限需求点，它可能低估完整 W1 目标，所以其目标值是下界：

\[
LB_r.
\]

### 5.3 Sample-wise separation oracle

固定 \(y^{(r)}\) 和 \(\eta^{(r)}\)，对每个正权重样本求解

\[
d_s^{\star(r)}\in
\arg\max_{d\in\mathcal D}
\left\{Q(y^{(r)},d)-\eta^{(r)}c(d,\hat d^s)\right\}.
\]

oracle 返回两个核心结果：

1. 最大值 \(\Phi_s(y^{(r)},\eta^{(r)})\)；
2. 一个达到该最大值的代表性最坏点 \(d_s^{\star(r)}\)。

### 5.4 检查违反并加点

若

\[
\Phi_s(y^{(r)},\eta^{(r)})
>t_s^{(r)}+\text{tolerance},
\]

则当前 master 漏掉了更坏的需求点。加入

\[
\mathcal K_s^{(r+1)}
=\mathcal K_s^{(r)}\cup\{d_s^{\star(r)}\}
\]

及其完整二阶段变量和约束，然后重新求解 master。

### 5.5 上界

oracle 在完整 box 上求得每个样本的真实最坏响应，因此当前 \((y^{(r)},\eta^{(r)})\) 的有效目标为

\[
UB_r
=\eta^{(r)}\varepsilon
+\sum_s\pi_s\Phi_s(y^{(r)},\eta^{(r)}).
\]

算法保留历次最小的有效上界及对应 \(y\)。

### 5.6 终止

当所有样本均无新违反点，且

\[
\frac{UB-LB}{\max\{1,|UB|\}}
\le\text{tolerance},
\]

CCG 收敛。此时 restricted master 已经包含决定最优解所需的最坏需求点，因而得到完整 box-supported W1 模型的全局最优目标和承运人决策（允许数值求解容差）。

## 6. 当前 box oracle 怎样得到最坏需求点

对二阶段 LP 作对偶后，可以写成

\[
Q(y,d)=max_{a,b,g,\sigma}
\left\{
\sum_ja_jd_j+
\sum_i p_i y_i b_i-
\sum_iM_i y_i g_i-
\sum_{i,j}q_{ij}\sigma_{ij}
\right\},
\]

满足相应对偶可行约束。对固定的 recourse-dual 斜率 \(a_j\)，第 \(j\) 个坐标在 oracle 中贡献

\[
a_jd_j-\eta\frac{|d_j-\hat d_j^s|}{\tau_j}.
\]

在区间 \([\underline d_j,\overline d_j]\) 上，其最大值可在以下三类点中达到：

\[
d_j\in\{\underline d_j,\hat d_j^s,\overline d_j\}.
\]

当前 oracle 为每条 lane 建立 `moveLower[j]` 和 `moveUpper[j]`：

- `moveLower=1`：移动到 lower；
- `moveUpper=1`：移动到 upper；
- 两者均为 0：保留 nominal；
- 两者不能同时为 1。

oracle 同时优化 recourse 对偶变量和这些端点选择，所以不是显式枚举 \(3^J\) 个组合，而是由一个 MILP 隐式选择最坏端点组合。

### 一维直观例子

历史需求为 100，支撑为 \([50,150]\)。oracle 比较：

\[
Q(y,50)-\eta c(50,100),
\]

\[
Q(y,100),
\]

\[
Q(y,150)-\eta c(150,100).
\]

- 高需求导致现货成本显著增加时，150 可能最坏；
- 低需求导致已选承运人的 MQC 罚金显著增加时，50 也可能最坏；
- 移动收益不足以覆盖距离代价时，100 最坏。

因此 oracle 找的是“净不利程度”最大的需求点，而不是简单寻找总需求最大值。

## 7. CCG 为什么可以知道精确最坏目标，却不必先知道最坏分布

Kantorovich 对偶已经把“搜索无限维概率分布”转化成：

1. 一个标量运输预算价格 \(\eta\)；
2. 每个中心样本的最坏位置问题 \(\Phi_s(y,\eta)\)。

只要所有 sample-wise oracle 都被精确求解，并且 CCG 不再发现违反点，对偶目标就等于原始最坏分布问题的目标。因此求最优决策和最坏期望值并不要求显式列出最坏分布的每个概率原子。

这与线性规划中“通过对偶变量得到最优值，但不一定主动输出原始最优流量方案”类似。

## 8. 当前 worst-demand 诊断具体是什么

在产生当前最优上界的 oracle 遍历中，对每个中心样本保留一个代表性 argmax：

\[
d_1^\star,\ldots,d_S^\star.
\]

当前代码计算：

\[
\text{meanNominalDemand}
=\sum_s\pi_s\hat d^s,
\]

\[
\text{meanWorstDemand}
=\sum_s\pi_sd_s^\star,
\]

\[
\text{meanWorstDistance}
=\sum_s\pi_sc(d_s^\star,\hat d^s).
\]

对 lane \(j\)：

\[
\text{upperMoveProbability}_j
=\sum_{s:d_{sj}^\star=\overline d_j}\pi_s,
\]

\[
\text{lowerMoveProbability}_j
=\sum_{s:d_{sj}^\star=\underline d_j}\pi_s.
\]

还记录：

- `meanMovedLanes`：代表性最坏点平均改变多少条 lane；
- `maxMovedLanes`：单个代表性最坏点最多改变多少条 lane；
- `meanNominalTotal` 与 `meanWorstTotal`；
- `eta`、box、distance scale、生成点数量、oracle 次数。

这些字段回答的是：

> 在最优 \(y,\eta\) 下，每个中心样本最有威胁的需求移动方向是什么？

它们不直接回答：

> 完整最坏分布最终向每个需求点分配了多少概率？

因此论文中宜称为 `oracle worst-point diagnostics` 或“代表性最坏需求点诊断”，不能直接称为“最坏分布均值”。

## 9. 为什么代表性最坏点不等于完整最坏分布

仍用一维例子。中心分布为

\[
\widehat P(D=100)=1,
\]

支撑为 \([50,150]\)，Wasserstein 半径只允许平均移动 10。oracle 可能判断 150 是最有威胁的位置，但把全部概率从 100 搬到 150 的距离为 50，超过预算。

一个可行的最坏分布可能是

\[
P^\star(D=150)=0.2,
\qquad
P^\star(D=100)=0.8,
\]

因为

\[
0.2\times50+0.8\times0=10.
\]

oracle 给出了目标位置 150，却没有单独给出概率 0.2。若存在多个并列 argmax，最坏分布还可能把一个中心样本的质量拆到多个需求点。

因此，直接令每个 \(\pi_s\) 全部移动到选中的 \(d_s^\star\)，可能违反半径约束，也可能不是原始问题的最坏概率分配。

## 10. 如何显式恢复完整最坏分布

CCG 收敛后，针对最终决策 \(y^\star\)，利用每个中心样本已经生成且在最终对偶下可能活跃的需求点集合 \(\mathcal K_s\)，定义

\[
\gamma_{sk}\ge0,
\]

表示从中心原子 \(\hat d^s\) 搬到生成点 \(d^{sk}\) 的概率质量。求解运输 LP：

\[
\begin{aligned}
\max_{\gamma\ge0}\quad
&\sum_s\sum_{k\in\mathcal K_s}
\gamma_{sk}Q(y^\star,d^{sk})\\
\text{s.t.}\quad
&\sum_{k\in\mathcal K_s}\gamma_{sk}=\pi_s,
&&\forall s,\\
&\sum_s\sum_{k\in\mathcal K_s}
\gamma_{sk}c(d^{sk},\hat d^s)\le\varepsilon.
\end{aligned}
\]

则目的点 \(d\) 在最坏分布中的概率为

\[
P^\star(d)
=\sum_{(s,k):d^{sk}=d}\gamma_{sk}.
\]

该 LP 还可输出：

- 最坏分布实际使用的 Wasserstein 预算；
- 每个中心样本保留/移动的概率质量；
- 最坏分布的真实均值和协方差；
- 每条 lane 的真实上移/下移概率；
- 最坏分布期望成本与 CCG 对偶目标的强对偶核验。

当前代码尚未实现这一步。若后续论文需要展示完整最坏分布，应新增独立 `worst-distribution reconstruction` 模块，而不能把现有 `meanWorstDemand` 改名后直接使用。

重构后还必须检查运输 LP 的最优值是否与固定 \(y^\star\) 的 W1 对偶目标一致。若存在差距，说明当前保存的生成点不足以恢复某些并列最坏原子，需要在固定最终 \(y^\star,\eta^\star\) 下继续执行支持点分离或并列最优点搜索，直到 primal transport LP 与 dual objective 在容差内一致。CCG 对目标和决策的认证本身不依赖这一步；该检查只针对“显式恢复一份最坏分布”。

## 11. 上下界与输出字段的正确解释

| 字段 | 正确含义 | 不应解释为 |
|---|---|---|
| `objective / bestUB` | 已找到决策的完整 W1 对偶目标上界 | 某一个最坏需求样本的成本 |
| `bestBound / LB` | restricted master 给出的全局下界 | OOS 成本下界 |
| `gap` | W1-CCG 上下界差 | CPLEX 某一次内部 master 的瞬时 gap |
| `eta` | Wasserstein 运输预算的最优对偶价格 | 人为设定的鲁棒参数 |
| `generatedCuts` | oracle 新发现并加入的需求点数量 | CPLEX 内部 cuts 数量 |
| `meanWorstDemand` | 代表性 oracle argmax 的中心概率加权平均 | 完整最坏分布的严格均值 |
| `upper/lowerMoveProbability` | 中心样本的代表性 argmax 命中端点的概率质量 | 最坏分布最终位于端点的严格概率 |

## 13. 后续读取时应坚持的口径

1. CCG 精确性指最优目标与决策，不代表代码已经显式输出最坏概率分布。
2. `meanWorstDemand` 等字段是机制诊断，不是 primal worst distribution statistics。
3. 如果只需要解释“哪些 lane 构成W1的不利方向”，当前字段足够。
4. 如果需要写“最坏分布有多少概率位于哪些需求点”，必须先实现第 10 节运输 LP。
5. 支撑、距离和中心权重是三件不同的事：
   - 权重决定中心分布；
   - box 决定允许生成新点的范围；
   - scaled-\(L_1\) 决定移动成本；
   - 半径决定总运输预算。
6. 当前正式口径是正权重样本中心、正权重样本逐 lane min/max box、scaled-\(L_1\) 距离；不要继续引用旧的 1.5 倍支撑规则。

## 14. 可直接用于论文或回复的准确表述

> We solve the box-supported contextual 1-Wasserstein model through an exact primal-block column-and-constraint generation algorithm. The restricted master contains the first-stage carrier decisions, the Wasserstein dual multiplier, and recourse blocks associated with demand points generated so far. For each positively weighted empirical atom, an exact separation oracle identifies a demand realization maximizing the recourse cost net of its transportation penalty. Violated realizations are added to the master until no violation remains and the global upper-lower bound gap satisfies the prescribed tolerance. This procedure certifies the worst-case expectation and the optimal first-stage decision without explicitly constructing a primal worst-case probability distribution. The reported worst-demand statistics summarize representative oracle maximizers; recovering the probability masses of a worst-case distribution would require an additional optimal-transport reconstruction LP.

## 16. `meanMovedLanes` 和 `maxMovedLanes` 到底怎样计算

对最终用于更新最优上界的 \((y,\eta)\)，oracle 为每个正权重中心样本 \(s\) 返回一个代表性最坏点 \(d_s^\star\)。首先对每个样本计数：

\[
m_s
=\sum_{j=1}^J
\mathbf 1\left\{|d_{sj}^\star-\hat d_{sj}|>\operatorname{tol}_j\right\},
\]

其中代码使用

\[
\operatorname{tol}_j
=10^{-8}\max\{1,\overline d_j\}.
\]

然后计算

\[
\text{meanMovedLanes}
=\sum_s\pi_sm_s,
\]

以及

\[
\text{maxMovedLanes}
=\max_s m_s.
\]

因此：

- `meanMovedLanes=1.31` 表示从中心分布按 \(\pi_s\) 抽取一个样本时，其代表性 oracle 最坏点平均改变约 1.31 条 lane；
- `maxMovedLanes=3` 表示至少有一个中心样本的代表性最坏点改变了 3 条 lane，且没有样本改变超过 3 条；
- `meanMovedLanes=0.073` 不表示“每个最坏点移动 0.073 条 lane”，而是概率加权期望。例如若每个被移动的最坏点只移动 1 条 lane，则它表示约 0.073 的中心概率质量对应的代表性最坏点发生了移动；
- 权重不等时，不能把 0.073 机械解释为 7.3% 的样本个数。

由于每个发生移动的 lane 必须命中 lower 或 upper，理论上有

\[
\text{meanMovedLanes}
=\sum_{j=1}^J
\left(
\text{lowerMoveProbability}_j+
\text{upperMoveProbability}_j
\right),
\]

允许数值容差误差。这给当前日志提供了内部一致性检查。

### 16.1 \(\varepsilon=0.01\) 的日志实例

某次 50-lane 求解输出：

\[
\text{meanMovedLanes}=1.3107419187,
\qquad
\text{maxMovedLanes}=3.
\]

其 lower 移动概率全部为 0；非零 upper 移动概率主要为：

\[
0.5527850906,qquad
0.0542528305,qquad
0.7037039976.
\]

三者之和为

\[
0.5527850906+0.0542528305+0.7037039976
=1.3107419187,
\]

正好等于 `meanMovedLanes`。这说明当前代表性最坏点主要把三个特定 lane 的一部分中心概率质量推向各自 upper，而不是把 50 条 lane 同时推到 box 角点。

该次诊断还给出：

\[
\text{meanNominalTotal}=41812.8212,
\qquad
\text{meanWorstTotal}=42994.8445.
\]

这两个数仍是“名义点/代表性 oracle argmax”的加权诊断，不是完整最坏分布均值。

### 16.2 \(\varepsilon=0.00025\) 的日志实例

另一次 50-lane 求解输出：

\[
\text{meanMovedLanes}=0.0731620545,
\qquad
\text{maxMovedLanes}=1.
\]

只有一条 lane 的 upper 移动概率为

\[
0.0731620545,
\]

其他 lower/upper 移动概率为 0。因此这次代表性 oracle 点最多只改变一条 lane，且发生这种移动的中心概率质量为 0.0731620545。

该次诊断为：

\[
\text{meanNominalTotal}=27080.2810,
\qquad
\text{meanWorstTotal}=27096.4572.
\]

### 16.3 这两个实例不能直接证明半径趋势

以上两个数来自不同 replication/origin/中心分布，不能据此直接得出

\[
\varepsilon\uparrow
\Longrightarrow
\text{meanMovedLanes}\uparrow
\]

或任何单调结论。要分析半径效应，必须在以下条件全部相同的严格配对下比较：

- 同一采购市场；
- 同一 query 和中心权重；
- 同一训练样本；
- 同一 box 和 distance scale；
- 分别求解不同 \(\varepsilon\)。

即使如此，最优 \(y\) 和 \(\eta\) 也可能随半径跳变，所以代表性最坏点数量不一定严格单调。可保证单调的是训练内最坏目标值关于歧义集半径非递减，而不是每一个诊断字段都单调。

## 17. W1 为什么可能比卡方更保守，但不存在普遍排序

### 17.1 两种歧义集保护的对象不同

卡方 DRO 只调整现有经验原子的概率：

\[
P_{\chi^2}=\sum_sp_s\delta_{\hat d^s}.
\]

它不能产生训练集中不存在的需求位置。W1 则允许把中心概率质量从 \(\hat d^s\) 搬到支撑内的新点，因此可以保护：

- 需求位置误差；
- 训练中没有精确出现但距离较近的不利需求；
- 少数 lane 向 upper/lower 偏移；
- box 内新的跨-lane组合。

因此 W1 的支撑移动能力确实比固定支持卡方更强。

### 17.2 矩形 box 带来的额外保守性

box 仅规定每条 lane 的上下界，并不规定 lane 之间的联合关系。即使 lane 1 和 lane 2 的历史最大值从未同时出现，box 仍允许二者同时偏高。W1 可以向这种历史中未出现的组合移动概率，而卡方不能。

这可能使 W1 更保守，也是 W1 的 OOS Mean 有时不如卡方的潜在机制之一。但当前 `meanMovedLanes/maxMovedLanes` 说明，已观察到的 oracle 通常只移动少数 lane，并非机械地把所有 lane 同时推到 upper。

### 17.3 为什么不能断言 W1 必然更保守

两类集合约束的量不同：

- 卡方约束概率相对中心权重的偏离；
- W1 约束概率质量乘以需求移动距离的总预算。

二者通常不构成集合包含关系：

\[
\mathcal P_{\chi^2}\not\subseteq\mathcal P_{W_1},
\qquad
\mathcal P_{W_1}\not\subseteq\mathcal P_{\chi^2}.
\]

而且 \(\lambda\) 与 \(\varepsilon\) 的量纲和含义不同，不能用相同数值比较保守程度。小 \(\varepsilon\) 的 W1 可能只移动极少质量；大 \(\lambda\) 的卡方也可能把大量概率集中到已有高成本场景。因此更准确的结论是：

\[
\boxed{
\text{W1具有更强的支撑移动能力，但实际保守性取决于半径、box、距离尺度和训练内选参。}
}
\]

### 17.4 正式比较需要观察什么

判断当前实例中谁更保守，应在相同中心权重、训练样本和 OOS pool 下比较：

1. 训练鲁棒目标相对 CSAA 增加多少；
2. 选中承运人数和具体组合；
3. 合同运输、现货和 MQC 成本分解；
4. W1 的代表性最坏点移动方向；
5. OOS Mean、SD、Q95、CVaR 和 Max；
6. 若需要严格讨论“最坏分布”，先完成第 10 节 primal transport reconstruction。
