## 1. W1 已冻结的定义及核验边界

对于每个 validation origin 或 final solve，使用当时的训练需求计算 `m_j=max_s d_j^s`。若所有 `m_j>0`，则

`c(d,d')=(1/J) Σ_j |d_j-d'_j|/m_j`, `Xi=∏_j[0,1.5m_j]`, `P_epsilon(P_hat)={P:W_{1,c}(P,P_hat)≤epsilon,supp(P)⊆Xi}`。

训练样本属于 `Xi`，所以中心分布本身可行、W1 球非空；`c` 是合法的 weighted L1 metric，且整个 box 的 ground-metric diameter 为1.5。`epsilon` 是 coupling 下的**概率质量加权平均搬运成本**，不是逐 lane 需求变动上限。正式候选绝对半径为 `{0.005,0.01,0.025,0.05,0.10,0.25,0.50,1.00}`；`epsilon=0` 只用于检查退化到等权 SAA 或相同权重的 CSAA，不进入常规半径调参。U-W1、C-W1 共用每个 origin 的训练需求、尺度、box、ground metric 和网格，各自仅以等权/条件权重构造不同中心，并用相同 validation criterion 独立选半径。不同规模继续使用同一无量纲半径数值，不再乘两两距离或 `J`。

这些公式与数值范围是**合理的实验设计**而非已有文献对该问题给出的唯一标准。证明 `diameter=1.5` 只能证明网格有明确尺度，不能证明八个点都能区分决策；正式 OOS 前应仅用训练/验证 pilot 记录最优半径频率、边界命中、不同半径的决策/目标是否饱和，必要时依半径文档规定一次性扩网格并冻结。`m_j=0` 时公式无定义，必须事前给出预处理规则；合成主实验正需求一般不触发，稀疏 Olist 若选做 W1 必须核验各内层窗口。高波动 Lognormal 真分布无界，而 W1 比较故意限于有限 box；可报告独立 OOS draws 超出 box 的比例，不能把 box 解释成真实物理上界。这些是诊断与表述边界，不是当前公式错误，也不要求现在另设半径方案。

工作区与外部返修目录的 `TSPP_SVU_numerical_experiment_manual_cn_reconciled_20260914.tex` 已同步上述 W1 公式、半径、U/C 比较和规模实验用法；最后同步的两副本 SHA-256 同为 `C78BAC51DA2D894E851F43D1607CBF2C674146BEDF4AD914EF9B955FB1596041`。同时同步了最新简短参数表中不涉及模型争议的 χ²常规/极限网格、`n=100` 取200路径前100、compact-support kernel validation 零权重候选 invalid。**仅文档已改；正式 Java/Python runner 的常数、metric 和支持集尚未据此统一核验或重跑。**用户此前暂停 PDF 编译，因此 TeX 仍无新版渲染验证。

## 4. 正式批量运行前的三个闸门

1. **参考权重唯一化。** Exp.1 可公平比较所有 nominal weighting methods；后续 RCSAA/χ²/W1 必须用同一个事前规则选 reference，建议固定指数 NW（保留与原方法和其统计动机的一致性），或完全通过每个 replication 的训练内 validation 选；二者选其一。绝不按同一 OOS 的赢家选，也不能在回复 Word 中同时声称固定指数、OOS选 `K*` 和validation选 `C*`。
2. **矩列模型与标签。** 若保留短 PDF 的边际均值—方差+κ网格，就要重新核对RSOME构造和近似决策规则；若走节省工作量路线，则保留已审计 MAD/PCM经验矩小型附录，明确是 lifted affine recourse 近似，不叫新 mean–variance 精确基准。
3. **RCSAA实际算法与状态。** 当前 repair-cut/local branching 与强化 compact 都有实现和历史测试，正式不能在 response letter 中预写“compact已替代原算法”。先用等式、相同实例与统一时限确认准确性、状态和规模表现，再决定主算法叙事；如果仍保留 local branching，补其邻域参数诊断。
