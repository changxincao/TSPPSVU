# SVU 合成数据生成：第一块（2026-09-14）

## 本轮边界

只实现《TSPP_SVU_numerical_experiment_manual_cn_reconciled_20260914.tex》的 synthetic Experiments 1--3 所用外生协变量与条件需求生成；不修改历史 lag-demand DGP，不生成采购报价、coverage、capacity、MQC，不接参数验证、求解器、实例持久化或正式 OOS 统计。后续模块复用现有 `Basic.Sample`、`CovariateVector`、`PeriodData` 输入。

## 实现及参数

新增 `src/Test/analysis/synthetic/TRBSVUSyntheticDemandGenerator.java`。`sampleParameters(J,H,seed)` 对每条 lane 生成一次固定参数：`mu0~U(10,30)`，`eta_M/eta_A/eta_C=mu0*U(.3,.6)`，`eta_T=mu0*U(.2,.4)`；同时保存一个共同的 `U(0,1)` 波动分位，用于将同一 lane 映射到 Low `[.1,.3]`、Medium `[.4,.6]`、High `[.7,.9]`，使六个 DGP cell 可以共享 nominal 参数。`typicalDemand()` 使用历史时间位置的解析平均 `E[T]=(H-1)/(2H)` 和三个随机 context 的 `E=.5` 计算采购模块将来可用的 `dbar_j`，不从实现的随机历史需求倒推市场规模。

每个历史 `t=1,...,H` 生成 `M,A,C~U(0,1)`，`T=(t-1)/H`，形成 `mu_j^t=mu0_j+eta_M M+eta_T T+eta_A A+eta_C C`。Normal 按 `N(mu,(c mu)^2)` 抽样并对负值重新抽取；因此 `c` 是 latent noise scale，不声称接受后的 CV 精确为 `c`。Lognormal 使用 `logVariance=log(1+c^2)` 和 `logMean=log(mu)-logVariance/2` 的等价乘法实现，条件均值恰为 `mu`、CV 为 `c`。给定 context 后，lane residual shocks 独立；跨 lane 关联仅来自共同 context。

`generate(...)` 输出 `H` 个连续历史 `Sample`、一个 `T=1` 的最终 test context，以及该固定 context 下的 `N` 个独立 OOS `Sample`；每个 OOS draw 复制同一 context，不错误生成新 query。参数、context、历史噪声、OOS 噪声使用分离的 seed。跨 DGP cell 复用同一个 `Parameters` 和 context seed 可配对 nominal path；同一 cell 的所有求解方法应复用整个 `Replication` 对象，以确保共享 realized history/OOS draws。

只读对照修订版 TeX 第60--136、226--238行及两个新增 Java 文件，并重新编译和运行六 cell 自检，结果仍为 PASS。已实现部分逐项一致：`J=60,H=100` 可由参数入口给出；`mu0~U(10,30)`；`eta_M/eta_A/eta_C~U(.3mu0,.6mu0)`、`eta_T~U(.2mu0,.4mu0)`；`M,A,C~U(0,1)`、`T=(t-1)/H`；`mu_j^t` 的四项系数顺序；`c_j` 的 low/medium/high 三档边际区间；Normal latent `N(mu,(c mu)^2)` 后负值重抽；Lognormal 的 `log(1+c^2)` 参数化；给定 context 后的 lane 独立残差；100个连续历史样本和固定一个 `T=1` 最终 context 的1000个 conditional OOS draws。`Sample` 历史/OOS权重分别赋 `1/H`、`1/N`，符合后续等权基准输入。

两项实现边界必须保留：一是六 cell 共享同一个 `Parameters` 与 context seed 时才严格共享 nominal 路径；目前生成器允许但正式 runner 尚未强制，采购市场也未生成。二是30个70周 rolling validation origins、20/10次 independent replications、方法共用样本、实例文件及正式OOS结果均属调度/保存/求解层，本轮尚未实现，不能把生成侧 PASS 称作整个实验协议完成。

另有两个**非阻断性的写作口径**：代码为配对六 cell 先对每条 lane 抽一个共同 `U(0,1)` 分位，再分别线性映射至三档 `c_j`；各档边际分布正确，但这种跨档 rank pairing 未在 TeX 中显式写出。`typicalDemand()` 将 `E[T]` 按100个历史期取 `(H-1)/(2H)=0.495`；TeX 说“synthetic horizon 中的 time position”而未逐字界定是否也计入最终第101期，若计入则为0.5。这是很小的口径歧义，不是现有生成公式与明示 `t=1..H` 的矛盾；正式写作宜明确 `dbar` 的平均时间范围。没有据此改动代码。

### 用户最终确认：`dbar` 不包含第101期

`T_t=(t-1)/H`，历史 `t=1,...,H` 时的平均为 `((0+1+...+(H-1))/H)/H=(H-1)/(2H)`；`H=100` 时为 `99/200=0.495`。第101期 `T=1` 只用于最终测试 context，不进入用于固定采购市场规模的历史平均。因此现有 `typicalDemand()` 实现正确；上段提出的“是否包含第101期”已由用户明确裁定，后续文档应写“对前H个历史期及其外生协变量分布取平均”，不再保留歧义。本轮未改生成代码。
