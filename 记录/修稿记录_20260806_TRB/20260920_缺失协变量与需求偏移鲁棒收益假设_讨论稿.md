# 缺失协变量与需求偏移下鲁棒收益：讨论稿（未验证）

日期：2026-09-20。本文先记录待验证假设，再按时间顺序追加受控试验及证据边界；以下各节须按其标注的时间和试验范围理解，不能把早期“尚未测试”的状态当作最终结论。

## 用户提出的四条线索

1. 缩小训练样本至约30；但样本过少可能被质疑。已有 S=30/45 探索出现承运人数饱和，不能当作新的可靠突破口。
2. 历史训练协变量偏低，而待决策 query 较高；query 的 OOS 仍应从真正的 P(D|x) 独立生成。此方案是 context 覆盖不足／外推测试，不是通常的同分布平均性能。
3. 协变量正常，但训练需求创新偏低、OOS创新偏高；这是人为的条件残差分布偏移，暂不作为优先方案。
4. 多数需求普通，少数需求很高；现有 mean-one lognormal 已有右尾，且 p=0.1 的均值校正共同跃升机制曾浅测，虽改善风险指标，却未稳定改善鲁棒 OOS Mean。不能把旧方案改名后当作未做过的新方案。

## 用户希望形成的完整论文故事（原意保留，均待验证）

用户首先希望找到至少一种**不刻意筛选有利结果**、且鲁棒法相对同权重CSAA能改善OOS均值的情形。可能的主线是：历史协变量对应的需求状态整体偏低，而当前决策面临较高协变量状态；因训练样本有限，CSAA对当前条件分布估计不充分，稳健化也许更能防止低估高需求与现货支出。用户认为这可以与真实Olist案例相互呼应：Olist不能提供全部真正重要的需求驱动协变量，且现实需求可能有无法由已知协变量预测的突变，故仅用历史条件加权经验分布可能偏离当前真实条件分布；鲁棒法可能弥补一部分误差。

用户进一步提出另一条信息缺失线索：仍由原有四类协变量生成需求，但某项特别关键的协变量在决策阶段不可获得；CSAA/RCSAA只能使用其余可见协变量。期待部分信息CSAA仍优于不使用协变量的SAA，但鲁棒法相比部分信息CSAA更有优势。与之形成对照，四类协变量都可观察且预测比较准确时，CSAA可能已经很好，正鲁棒参数对均值改善很小、可能稍差，但仍可能降低SD和尾部风险。若这些分层现象经完整样本验证，就可以清楚说明稳健化在“信息充分”与“信息不完整／分布偏移”条件下的边界，而不是强求每个场景都严格单调。

用户还考虑过少样本（如30个）、训练需求创新偏低/OOS创新偏高，以及“多数需求正常或偏低、少数需求特别高”的右尾。少样本易受审稿质疑；刻意压低训练创新、提高测试创新不好作为论文主线；右尾如可由一个简单、合理的分布机制体现则值得检查。若完整协变量主设置没有显著鲁棒均值收益，用户希望通过合理的缺信息或训练/测试条件状态差异寻找收益，而不是只靠事后挑选半径、query或seed。所有方向目前都是研究假设，不能在论文中先写成事实。

## 关键逻辑边界

将某个实际起作用的协变量 Z 从 CSAA/RCSAA/χ² 的输入中删去，而需求生成仍使用全部 X，是“部分可观测协变量”实验。如果训练和测试来自同一联合分布，且未观测 Z 在给定可观测 X 下的分布不变，那么充分数据下部分信息 CSAA 学到的是混合条件分布 P(D|X_observed)，并非必然系统性低估。鲁棒法仅可能缓解有限样本估计误差、尾部低估，并无必然均值优势。如果测试时未观测 Z 的分布相对训练期发生变化，才构成额外的隐藏状态分布偏移，须明确标注为单独实验。两者不能混写。

低 X 训练／高 x query 则是另一种 context 外推：核权重可能集中在很少的训练点；当前 RCSAA/χ² 主要改变已观测需求场景的概率，不能创造训练支持中没有的高需求。因此该机制可能使所有样本法一同失效，并非保证鲁棒胜出。

不可预测的需求突变若在训练与OOS都按同一预定机制随机出现，属于同分布稀有尾部；若只放在OOS，则是压力／分布偏移实验。χ²/RCSAA能重加权历史中出现的尾部；若训练样本完全没有该尾部，方法不能凭空补出。原始Olist可能存在未观测驱动或变化，但现有数据并不能证明它们是鲁棒收益的原因，只能作为待验证解释或案例限制。

## 建议的最小对照顺序

首先在冻结的同一采购市场、历史、query和共同OOS下，比较：完整四维协变量 CSAA／正半径鲁棒；只遮蔽**事前按生成系数或可得性指定**的一维后的部分信息 CSAA／同口径鲁棒；SAA 作无条件参照。遮蔽只改变方法可见的特征，不改变真实生成器或OOS；各方法参数只用训练／验证集选。报告全部预先抽取的query及配对 OOS Mean、SD、q95、CVaR、组合、现货与MQC成本、有效样本数、正半径选中频率；可按隐藏 Z 的高低做事后机制分层，但不能只报有利组。

若遮蔽本身未带来鲁棒均值收益，再单独、明确标注“低训练X／高query”的覆盖不足情景；这不能替代同分布主实验。稀有右尾先沿用既有lognormal／跃升记录，不再仅凭“少数很大”重复试验；只有提出新的、预先声明且合理的残差机制时再试。S=30和训练残差刻意偏低不作为当前主线。

判定标准：正半径鲁棒在完整配对样本上的OOS Mean是否真低于同特征CSAA，风险是否同步改善；若增签，还须检查非MQC成本节省能否覆盖MQC增量。不得用看过OOS后的query、seed或半径筛选证明主结果。完整信息条件期望的理想最优决策是OOS Mean下界，正则化对有限样本可纠错但不会系统性打败它。

参考：Wang et al., *M&SOM* (2026), DOI 10.1287/msom.2024.0997，讨论条件NW的有限样本正则化；Duque et al., *SIAM J. Optimization* (2022), DOI 10.1137/20M1370227，说明两阶段鲁棒法收益依赖数据分布与半径。两文不证明本项目的缺失协变量实验必然出现均值改善。

## 2026-09-20受控初测：低历史协变量／高query（运行中）

固定既有第269/271组的参数与采购市场：`I=15,J=50,S=50`、默认随机50% coverage、固定采购设计1、`LOGNORMAL/MEDIUM`、`SQUARED_GAUSSIAN_POSITIVE_CENTERED`与context scale 1.95、区域需求因子`K=5,tau=0.5`、共同载荷`U(0.2,0.6)`、`B=0.5`、MQC数量scale 1.75、spot scale 1.5、`h=min r`。每个query用500个独立OOS评价。对照三档`shift=0,0.2,0.4`，各自六个事前确定、未按结果筛选的query；固定χ²`lambda=0.05`，同组比较D/SAA/CSAA/C-χ²。全部方法共享采购市场、参数种子、协变量原始随机数以及逐个需求创新。这里只是pilot，`B`和`lambda`均不是训练内选参结果。

采购市场在三档shift之间**完全固定且不重新按偏移后的需求校准**；这模拟签约条件已定、随后需求状态改变。它是有意的经济口径，不是只改变统计估计而保持供需比恒定。若正式写作采用此机制，必须明确这一点，因为更高query需求同时会增加现货暴露、降低MQC短缺，并可能改变所有方法的成本水平。

代码令训练期各维`X_train=(1-shift)U_train`，当前query各维`x=shift+(1-shift)U_query`，其中原始`U`仍来自独立Uniform(0,1)。需求只按新旧条件均值之比缩放：`D_new=D_old*mu(X_new)/mu(X_old)`。对于当前context-independent-CV的乘法lognormal及区域因子DGP，这严格保留每一个已抽出的单位均值创新；因此改变的是协变量抽样范围和条件均值，不是额外人为上移OOS残差。`shift=0`直接复用原样本。该入口明确拒绝与context-dependent CV或非Uniform context同时使用。生成器自检核对每个样本的协变量映射及标准化创新不变，已通过；Java编译通过。具体入口为`TRBSVUPersistentRateMqcMethodProbe`最后一个可选参数`context-shift`，输入统计为`TRBSVUContextShiftInputDiagnostic`。

输入审计（同一市场和随机数）：`shift=0`时训练名义／实现总需求平均约2537.58／2523.05，训练实现需求最大4513.92；`shift=0.2`时为2041.84／2030.05，最大3626.60；`shift=0.4`时为1546.10／1537.06，最大2739.28。六个query的OOS总需求超过训练最大值的比例，在`shift=0.2`分别为0%、13.0%、36.4%、2.6%、47.8%、14.4%；在`shift=0.4`分别为31.0%、90.2%、96.8%、76.0%、97.6%、90.2%。因此0.4显然是强支持错配，不能拿其结果代表温和现实偏移；0.2是较温和、仍有部分历史覆盖的诊断。

运行目录：`analysis/TRB_reviewer_revision/310_low_context_high_query_20260920/candidate_shift_{0.0,0.2,0.4}/`。为使现有试探入口只求候选采购市场，使用`oracleSamples=1`跳过额外的`CURRENT`市场；输出中名为`ORACLE`的单样本解**没有oracle含义，必须完全排除分析**。每个query的正式OOS仍是其余500个需求抽样。历史上最初两个`shift_{0.0,0.4}`目录曾启动包含额外`CURRENT`市场的试跑，为节省时间在该市场未做完时停掉；不可用于最终配对汇总。正式分析仅使用上述`candidate_shift_*`三个完整输出目录，并逐项核对求解状态。

### 补充解释：训练均值差、强偏移同解及Olist的lambda证据

`shift=0.2`、query 1、`lambda=0.05`的81.94是**在同一组50个核加权训练场景上，χ²所选组合的普通加权平均成本减去CSAA组合的普通加权平均成本**：155684.4500−155602.5120=81.9380，约占后者0.053%。它不是χ²鲁棒目标的差，也不是OOS差。两个组合的训练加权SD分别为40653.1183和46325.2449；本点两者均处于无lift区间，故χ²目标等于加权Mean+`lambda`×加权SD。χ²组合的目标为157717.1060，CSAA组合若放入同一χ²目标约为157918.7743，χ²组合低约201.67。这说明模型愿意牺牲约82的训练均值换取约5672的训练SD下降；其独立OOS Mean恰好降低7032.85，但这只是此query的结果，不是一般保证。

`shift=0.4`、`lambda=0.1`的六个query均选8家，尚未触及`I=15`下的11家选人上限；χ²并非没有生效，它们相对同组合的CSAA训练均值各增加约3015—3085的正风险惩罚。只是当前参数下这一惩罚未使任何备选整数承运人组合胜出。此档训练实现总需求均值1537.06、最大2739.28；六query的真实条件均值约2542—3843，六组OOS中超过训练总需求最大值的比例为31.0%、90.2%、96.8%、76.0%、97.6%、90.2%。因此固定支持概率重赋权不能创造绝大多数未观测高需求是**可信的结构性限制**；但目前没有逐个备选组合的训练鲁棒目标分解，不能断言它是“同解”的唯一或已证明直接原因，更不能断言更大lambda也无效。需要把“支持错配”与“半径尚不足以跨整数阈值”分开。

## 2026-09-20补充解释：“无偏移／有偏移”到底改变了什么

这里的`shift=a`是**协变量分布的诊断性错位**，不是把OOS需求统一乘以`1+a`。四个原始协变量均由`U~Uniform(0,1)`产生；代码把每个历史样本改为`X_train=(1-a)U_train`，把待决策query及其OOS条件改为`x_query=a+(1-a)U_query`。所以`a=0`时训练和query均覆盖`[0,1]`；`a=0.2`时分别为`[0,0.8]`和`[0.2,1]`；`a=0.4`时分别为`[0,0.6]`和`[0.4,1]`。例如原始数值都为0.5，一维协变量在`a=0.2`的训练/query分别变为0.4/0.6，在`a=0.4`分别为0.3/0.7。四维均作同一变换。实现见`src/Test/analysis/synthetic/TRBSVUSyntheticDemandGenerator.java`的`shiftLognormalContexts`。

当前`SQUARED_GAUSSIAN_POSITIVE_CENTERED`生成器给四个协变量的是非负系数，因此较高的query协变量对应较高的条件平均需求。需求实现值按新旧`nominalDemand(x)`之比缩放，保留每个样本原有的lognormal相对创新；也就是说**给定x的需求生成规律并没有改**，改的是训练X与query x的抽样区间及其引起的总需求水平。采购市场、合同容量、MQC、费率及随机种子固定不动。不能把本试验说成“隐藏变量”或“OOS残差被人为抬高”，更不能视为Olist真实时间漂移的直接证据。

同一采购市场和六个固定原始query随机数下的量级如下；需求均为50个训练样本的名义总需求均值／六个query的名义总需求均值，CSAA成本为各query 500个OOS再对六query等权平均。三个shift对应**不同的真实query需求**，故跨档成本不能按相同需求样本直接相减；只能在每档内部配对比较CSAA和χ²。

这说明固定采购参数下，随着query需求从约2512升至3367，CSAA原方案的现货费从约38359升至120828，而MQC罚金从14636降至474。λ=1倾向增签：三档相对CSAA的现货节省依次为5548.91/19253.57/24263.75，合同加MQC增量依次为9210.19/15133.90/9888.18；因此净OOS Mean分别**上升**3661.27、**下降**4119.67、**下降**14375.57。用人话说：没有偏移时需求整体较低，多签的MQC代价通常不划算；query越来越高时，原方案越来越依赖昂贵现货，多签的节省开始覆盖代价。

**重要识别边界**：当前shift操作同时（A）拉开了训练与query协变量分布，也（B）在固定合同下提高了query本身的需求水平；从这三档结果不能把χ²收益全部因果归于“训练—测试错位”。即使训练X不变而只提高query x，现货/MQC的经济权衡也可能朝同一方向变化。若论文要单独证明鲁棒法抵御covariate shift，而非仅在高需求query更合算，应另做固定市场的两个独立因素对照：只改训练X、只改query x，再与同时改变对比。当前没有运行这两个解耦对照，故本轮只证明**所定义的联合诊断情景**在该市场出现上述收益，不能把机制写得比证据更强。

## 2026-09-20重新分析：同分布、无偏移时能否仍有较大鲁棒均值收益

先纠正一条重复建议：基准DGP的每条lane相对CV固定，但绝对标准差本来就满足`SD(D_j|x)=mu_j(x)CV_j`，已随context改变。额外令CV本身随促销或条件总需求改变的两个诊断亦已完成，分别使正χ²相对CSAA的OOS Mean恶化约0.724%和1.001%；不能把条件异方差重新当作未测试的主要希望，证据见`20260919_鲁棒均值问题_门槛复核与DGP判别.md`。

已有oracle-proxy、缩样本、共同冲击、稀有右尾、异质右尾、区域因子、增加承运人及小带宽试算说明：不能从“CSAA有估计误差”或“高需求时现货费大”直接推出正鲁棒半径改善均值。近期`shift=0.2/0.4`的有利结果同时改变训练与query分布及query需求/固定合同之比，最有信息量的**未完成识别试验**是仅重排context抽样区间，而不改需求公式、采购市场、成本、种子及方法：设低区间`L_a=U(0,1-a)`、高区间`H_a=U(a,1)`，四维独立同样处理；比较`L_a/L_a`（同分布低状态）、`L_a/H_a`（已运行的错位）、`H_a/H_a`（同分布高状态），另保留`U(0,1)/U(0,1)`旧基线。每格独立OOS均按该格query的相同条件DGP生成，并在格内配对比较CSAA与正χ²。首先预先固定`a=0.2`及`0.4`、固定同一采购市场，只作机制诊断；跨格成本水平不直接比较。若`H_a/H_a`仍显著改善，说明训练—query错位并非必要条件，高需求相对固定合同的经济松紧可产生无偏移收益；若只有`L_a/H_a`改善，则目前证据支持的主要是训练不足/错位情景，不能把收益迁移到同分布主实验。若`H_a/H_a`改善，也不得立即把较高状态市场作为唯一主DGP：须按训练分布重新校准采购参数，跨未筛市场/replication并训练内选参，检查改善是否仍存在；否则只是旧合同与新常态不匹配。上述试验迄今尚未运行，不能预报结果或承诺5%以上。
