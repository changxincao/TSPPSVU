# covariate

## 这个目录总体做什么
这一组是协变量诊断工具，核心任务不是求解模型，而是先判断“这个协变量值不值得拿去做 CSAA / RCSAA”。
重点关注两件事：
- 协变量距离和未来需求距离是不是一致。
- 基于协变量算出来的权重，是过于集中还是过于平均。

这一组通常是正式求解前的前置诊断工具。

## 文件作用
- `covariate_quick_eval.py`
  - 快速评估不同协变量设计的效果。
  - 典型输出包括：`corrTheta_demandDist`、负相关比例、ESS、近邻占比等。
  - 主要回答“这个 theta 设计有没有信息量”“W 取多大更稳”“raw 和 PCA 哪个更合适”。

- `ThetaWeightScan.java`
  - 在 Java 求解口径下扫描权重分布情况。
  - 主要回答“在当前 `C_h` 下，权重到底是很尖还是接近均匀”“为什么某个 `C_h` 会更像 SAA，或者过于激进”。
